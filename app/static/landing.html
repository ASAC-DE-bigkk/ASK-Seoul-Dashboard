Why it's different

Contract enforced

모든 published 테이블은 컬럼·타입 계약을 선언하고, dbt가 빌드 단계에서 강제합니다. 상류가 바뀌어도 조용히 깨지지 않습니다.

Quality by row

행 단위 quality_status로 공간 매칭 정밀도를 투명하게 공개합니다. 쓸지 말지는 지표를 보고 소비자가 판단합니다.

Full lineage

원천 API 응답(raw)부터 bronze·silver를 거쳐 gold까지, 모든 데이터셋의 상류 계보를 카탈로그에서 바로 추적합니다.

API-first

탐색 화면이 쓰는 것과 동일한 조회 전용 REST API를 그대로 제공합니다. OpenAPI 문서와 스키마 계약 포함.

화면이 아니라
API가 제품입니다

마켓플레이스의 모든 정보 — 목록·스키마·품질·계보·샘플 — 는 GET /api/v1/catalog/… 엔드포인트의 응답을 그대로 그린 것입니다. 대시보드, Q&A 봇, 노트북 어디서든 같은 API를 소비하면 됩니다.

terminal
$ curl -s localhost:8765/api/v1/catalog/tables/gold_culture_sports_schedule/quality
{
  "name": "gold_culture_sports_schedule",
  "quality": [{
    "table": "silver_culture_sports_event",
    "distribution": { "dong_precise": 67 }
  }]
}
