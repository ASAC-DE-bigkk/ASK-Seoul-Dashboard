# Charts Studio 사용 가이드

대상: 화면을 사용하는 사람. 설계 배경은 [charts-design-intents.md](charts-design-intents.md),
켜고 끄는 법은 [operations.md](operations.md).

## 0. 진입

- 마켓플레이스(`/catalog`) 왼쪽 사이드바 **Platform › Charts Studio** (막대 차트 아이콘, NEW 태그)
- 또는 직접 `http://127.0.0.1:8765/charts`

## 1. 화면 구성

```
┌ 사이드탭 ────────┐ ┌ 톱바 ──────────────────────────────────────────┐
│ LAYOUT PAGES     │ │ 경로 · DEV │ 갱신 카운트다운 │ [간격▾] [레이아웃 변경] │
│  ▸ 상권 개요   6 │ ├──────────────────────────────────────────────┤
│  ▸ 업종 동학   4 │ │                                              │
│  ▸ 타임랩스   1 │ │   차트 타일 그리드 (12컬럼)                     │
│  [+ 레이아웃 추가] │ │                                              │
│ PLATFORM …       │ │                                              │
└─────────────────┘ └──────────────────────────────────────────────┘
```

기본 제공 시드는 상권 4페이지(상권 개요 · 업종 동학 · 타임랩스 · 지역 심층)와
**도메인 골드** 1페이지다. 도메인 골드는 문화·교통·날씨·도시데이터·대중교통의 대표
실측 차트를 한 화면에서 바로 비교한다.

## 2. 레이아웃 페이지 (왼쪽 사이드탭)

| 하고 싶은 것 | 방법 |
|---|---|
| 페이지 전환 | 목록에서 클릭 |
| 페이지 추가 | 목록 아래 **+ 레이아웃 추가** → 이름 입력 (추가 직후 편집 모드로 시작) |
| 순서 변경 | 페이지 **우클릭 → 위로 이동 / 아래로 이동**. 작은 화면은 톱바 `⋯` 메뉴 |
| 이름 변경 / 복제 / 삭제 | 페이지 **우클릭** 또는 작은 화면의 톱바 `⋯` 메뉴 |
| 페이지가 많아질 때 | 사이드탭의 페이지 목록만 스크롤된다(다른 영역 고정) |

## 3. 레이아웃 편집 — 배치는 편집 모드에서만

1. 오른쪽 위 **레이아웃 변경** 클릭 → 편집 모드(노란 배너·모눈 배경)
2. 타일을 **드래그**로 이동, 우하단 모서리로 **리사이즈**
3. 타일 오른쪽 위 아이콘: ↻ 다시 조회 · ✎ 차트 편집 · 🗑 차트 삭제
4. **레이아웃 저장** → 배치 확정(일반 화면에서는 움직이지 않음) / **취소** → 되돌리기

> 저장 전 다른 페이지로 이동하거나 창을 닫으면 경고가 뜬다. 변경은 저장을 눌러야 영속된다.

## 4. 차트 추가 — 3단계 드로어

편집 모드에서 **차트 추가**:

1. **소스** — gold 테이블 선택. 한국어 도메인 칩과 건수, 검색으로 좁힌다.
   현재 정책과 실제 필드 조합으로 차트를 만들 수 없는 소스는 선택 목록에 나오지 않는다.
2. **도표** — 14종 중 **실제로 구성 가능한 형태만 추천 순으로 표시**되고,
   컬럼 형태에 잘 맞는 도표에는 **추천 배지**가 붙는다(파란 강조).
   배지 카드에 마우스를 올리면 "왜 이 도표인지"가 툴팁으로 보인다
   (예: *"'연월'이 흐르는 소스네요 — 추세는 선으로 이어야 눈이 따라가요."*).
3. **연결** — 슬롯(축·값·시리즈·지역…)에 필드를 매핑하고 집계·옵션·필터 설정 → **미리보기** → **추가**.
   필터 아래 **추천 조합** 칩(⚡)을 누르면 소스×도표에 맞는 바인딩·집계·옵션이
   위 폼에 한 번에 적용되고 미리보기가 자동 실행된다. 수동으로 바꾸면 선택 표시가 풀린다.

> 추천은 특정 테이블에 하드코딩된 게 아니라 **컬럼의 의미역(시간/지역/분류/측정값)과 이름 패턴**
> (건수형→합계, 비율형→평균)에서 그때그때 계산된다 — 새 테이블이 실려도 그 모양에 맞게 추천된다.
> **추가/적용을 바로 눌러도 현재 초안을 먼저 실데이터로 확인**한다. 질의 오류나 0행이면
> 레이아웃에 넣지 않고 미리보기 영역에서 이유를 보여준다.

| 항목 | 설명 |
|---|---|
| 슬롯 | 도표가 요구하는 역할. `*` 필수. 이미 다른 필수 슬롯에서 쓴 필드는 다음 선택창에서 제외된다 |
| 집계 | 필드 의미와 옵션상 유효한 것만 표시. 온도·확률·농도·속도는 합계가 빠지고, 원형은 합계/건수만 가능하다 |
| 상위 N | 축 항목 수 제한 (값 기준 상위) |
| 옵션 토글 | 가로 막대·누적 / 곡선·면적 / 도넛 등 도표별 상이 |
| 필터 | 먼저 필드를 고른 뒤 해당 role에 맞는 한국어 조건만 표시. 숫자는 유한한 숫자로만 비교하며, 코드 사전이 있는 값은 실제 값 선택창으로 제공하고 목록/범위는 화면 안내대로 선택하거나 쉼표로 입력한다 |

물리 측정값이 없는 행사·경기 일정은 **행 수(count \*)**를 값으로 사용한다. 실제로 없는
가상 컬럼을 선택창에 만들지 않고 날짜·장소·지역별 레코드 건수를 집계한다.

도표 14종: 스탯 카드 · 막대 · 선 · 원형 · 산점도 · 히트맵 · 테이블 · **타임랩스 경주** ·
지도(서울 자치구 / 서울 행정동 / 서울 법정동 / 대한민국 시도 / 세계 / 좌표 밀도)

> **타임랩스 경주**: 시간축이 있는 소스에서 기간 프레임을 영상처럼 재생하며 순위 변화를
> 보여준다(기본 비누적·상위 12·기간 라벨 표시). 타일 아래에서 **이전/다음 프레임 · 재생/정지 ·
> 0.5×/1×/1.5×/2× 속도**를 즉시 조절한다. 연결 단계에서는 누적/구간, 상위 N,
> 기본 프레임 간격(ms)을 정한다. 누적은 개·폐업처럼 시간 합산이 안전한 흐름 지표에서만
> 선택할 수 있다. 자동 갱신 뒤에도 재생 상태·프레임·속도를 이어받는다.

소스를 고르면 실데이터의 필드별 null 아닌 값 수를 한 번 확인한다. 값이 전혀 없는 필드는
축·측정값·필터 선택지에 나타나지 않으며, 남은 필드로 만들 수 없는 도표 타입도 자동으로 숨긴다.
Trino 확인이 실패하거나 stale 캐시뿐이면 경고를 표시하고, 미리보기에서 빈 결과 저장을 다시 막는다.

## 5. 타일 읽는 법

| 표시 | 의미 |
|---|---|
| `● live` | 방금 Trino 에서 집계한 결과 |
| `● cached` | 서버 캐시(기본 10분 이내) 결과 |
| `● stale` (노란 점) | **Trino 접속 불가** — 마지막 성공 결과를 임시 표시 중 |
| `413/416 매칭 · 동명 모호 1 제외` | 지도 폴리곤 매칭 커버리지. 동명이동은 이중 표시 대신 제외 |
| `재바인딩 a→b` | 저장된 필드가 사라져 같은 역할의 다른 필드로 자동 연결됨 |
| `행 상한 도달` | 서버 행 상한(5,000)에 걸림 — 부분 데이터일 수 있음 |
| 우하단 `123ms` | 라이브 질의 소요 시간. 노트에 마우스를 올리면 실행된 SQL 확인 |

## 6. 자동 갱신

- 톱바의 간격 선택: **끔 / 1분 / 5분 / 10분(기본) / 30분 / 1시간** — 선택은 브라우저에 저장
- 주기마다 서버 캐시를 **우회(force)** 해 gold 를 다시 집계하고, 그려진 차트는 깜빡임 없이 교체
- 카운트다운·마지막 업데이트 시각이 톱바에 표시
- 편집 중이거나 탭이 백그라운드면 건너뛰고, 돌아오면 밀린 갱신을 즉시 수행
- 수동 갱신은 타일의 ↻ (역시 캐시 우회)

> 화면 갱신 주기 ≠ 데이터 적재 주기. gold 자체는 Airflow DAG 스케줄(일 단위)로 갱신된다.

## 7. 자주 겪는 상황

| 증상 | 원인/해결 |
|---|---|
| 모든 타일이 stale | Trino 다운 — [operations.md](operations.md) §4 |
| "데이터가 없습니다/측정값이 비어 있음" | 필터 값과 선택한 측정값 확인. 0행·전부 null인 설정은 추가되지 않는다 |
| 지도에 일부 동이 비어 있음 | 커버리지 표기 확인 — 좌표/코드 결측('UNK')이나 동명 모호 제외분 |
| 새 테이블이 소스 목록에 없음 | 카탈로그 스냅샷 갱신 필요 (`python extract.py`) |
| 실수로 배치를 망침 | 저장 전이면 **취소**, 저장 후면 다시 편집. 시드로 전체 리셋은 operations §3 |
| 작은 화면에서 페이지를 관리하고 싶음 | 톱바의 레이아웃 선택 상자 사용. `＋`는 추가, `⋯`는 이름·복제·순서·삭제 |
